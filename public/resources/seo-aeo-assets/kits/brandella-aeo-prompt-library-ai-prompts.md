# AEO Prompt Library: AI prompt pack

From Brandella Journal, free to use. Full guide: https://brandella.in/resources/seo-aeo-assets/aeo-prompt-library/

Replace the parts in [square brackets] before you paste a prompt into ChatGPT, Claude or Gemini. Always check the output against real data.

## 1. Turn customer words into prompts

```
Here are real messages from my customers, sales calls or support tickets: [paste]. Turn them into 20 prompts a person
would type into ChatGPT or Gemini when looking for a product like mine. Keep their words. Do not name my brand.
```

## 2. Fill gaps by intent type

```
Here is my prompt library with intent types: [paste]. My category is [category] for [audience] in [location].
Write 3 more prompts for each intent type that has fewer than 3: recommendation, comparison, alternatives,
problem or how to, pricing, brand facts, reviews and trust, local.
```

## 3. Persona variants

```
Rewrite this prompt in the voice of 5 different buyers, each with one line of real context (team size, budget, tool they use now,
country): "[prompt]". Keep the core need the same. No brand names unless the original has one.
```

## 4. Long conversational versions

```
People ask AI assistants long questions with constraints. Turn these short prompts into realistic 20 to 40 word versions
with a budget, a deadline or a must have feature: [paste prompts].
```

## 5. Find prompts in Bing grounding queries

```
Here are grounding queries from the AI Performance report in Bing Webmaster Tools: [paste]. Group them by intent type and
turn the 15 most useful into natural prompts for my library.
```

## 6. Read an answer into the Test Log

```
Here is an AI answer to the prompt "[prompt]": [paste answer]. List every brand it names, in order, separated by commas.
Then say whether it links to [my domain], its tone about [brand] (positive, neutral, negative or not mentioned) and any
claim about [brand] that I should check. Do not judge accuracy yourself.
```

## 7. List the sources an answer relies on

```
Here is an AI answer with its cited links: [paste]. List each source, what type it is (brand site, review site, directory,
news, forum, comparison article) and which brand it supports.
```

## 8. Why a competitor wins a prompt

```
For the prompt "[prompt]", answers name [competitor] far more often than [brand]. Here are the cited sources and what they
say: [paste]. Based only on this, give the likely reasons and 3 things [brand] could do about it.
```

## 9. Hunt down the source of a wrong fact

```
AI answers say this about [brand]: "[wrong claim]". The truth is: [correct fact]. List the kinds of places this old or wrong
claim usually comes from and a search I can run for each one to find copies of it.
```

## 10. Write a correction page section

```
Write a short, factual section for our [page] that states the correct [fact type]: [correct facts]. Make it easy to quote:
a clear heading, one direct sentence first, then the details and the date it changed.
```

## 11. Answer a negative review theme

```
AI answers say users complain that [complaint]. Here is what we changed and our proof: [paste]. Write a calm, specific
public reply and a short proof section for our site. No hype.
```

## 12. Honest comparison page outline

```
Outline an honest comparison page: [brand] vs [competitor] for [use case]. Include a summary table, who each one is best for,
pricing as of [date] and where the competitor is stronger. Mark every fact I must verify.
```

## 13. Get on the lists the engines cite

```
These list articles and directories are cited when AI assistants answer "[prompt]": [paste]. For each one, suggest a fair
way to be considered (update request, review, data, expert quote) and what proof I should send.
```

## 14. Unbranded answer page

```
No brand is named for the prompt "[prompt]". Outline the clearest page on the web for this question: a 40 to 60 word answer
first, then sections with our own data and examples from [brand]. Mark facts to verify.
```

## 15. Monthly change summary

```
Here are last month's and this month's mention rates by prompt and engine: [paste]. List the biggest gains and losses,
the prompts that changed status and what to check first.
```

## 16. Share of voice report for a manager

```
Write a short update for my manager. Data: [paste Dashboard and Share of Voice numbers]. Explain our mention rate, share of
voice against competitors, wrong facts found and fixed, and the plan for next month. No jargon.
```

## 17. Review the Fix Plan results

```
Here is my Fix Plan export with problem, source fixed, done date and rates before and after: [paste]. Which fixes moved
the rates? What should we do more of and what should we stop?
```

## 18. Workflow 1 of 5: brief the assistant

```
You are my AI visibility testing assistant. My brand: [brand], also written as [alias]. Competitors: [list].
Category: [category]. Audience: [audience]. Country: [country]. Rules: never invent facts, keep customer wording,
no brand names in unbranded prompts. Confirm, then wait for the next step.
```

## 19. Workflow 2 of 5: prompts from customer language

```
Here is real customer language: [paste]. Write 24 prompts, 3 for each intent type (recommendation, comparison, alternatives,
problem or how to, pricing, brand facts, reviews and trust, local), as a table: ID, Prompt, Intent type, Funnel stage.
```

## 20. Workflow 3 of 5: persona variants

```
For the 8 recommendation and problem prompts above, write one persona version each with one line of real context,
the way a busy person would actually ask. Add them to the table with new IDs.
```

## 21. Workflow 4 of 5: read a test answer

```
I ran prompt [ID] in [engine]. Here is the answer: [paste]. Extract the brands named in order, whether it cites [domain],
the tone about [brand] and any claim about [brand] I should check.
```

## 22. Workflow 5 of 5: log it

```
Turn that into one tab separated row for my Test Log: Date, Prompt ID, Engine, Mode, Brands named in the answer,
Your URL cited?, Cited URL or source, Tone about you, Facts about you, What it got wrong. Use [today] and "Logged out, fresh chat".
```
