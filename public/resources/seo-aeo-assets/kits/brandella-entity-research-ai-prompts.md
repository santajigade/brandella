# Entity Research: AI prompt pack

From Brandella Journal, free to use. Full guide: https://brandella.in/resources/seo-aeo-assets/entity-research/

Replace the parts in [square brackets] before you paste a prompt into ChatGPT, Claude or Gemini. Always check the output against real data.

## 1. List the entities in a topic

```
I am writing a page about "[topic]" for [audience]. List the 20 most important entities (people, places, organizations, products, events and concepts)
a complete answer must cover. For each give the type and one line on how it connects to [main entity]. Do not invent names.
```

## 2. Extract entities from competitor text

```
Here is the text of a top ranking page for "[keyword]": [paste]. List every entity it names, with its type and how many times it appears.
Mark the 5 the page treats as most central.
```

## 3. Entities from People also ask

```
Here are the People also ask questions and related searches for "[keyword]": [paste].
List the entities and attributes these questions are about, and group them by the section of a page they belong in.
```

## 4. Disambiguate a name

```
The name "[entity name]" could mean several things. List the possible meanings, and for the one that fits a page about [topic],
describe it in one sentence so a reader cannot confuse it. Suggest what kind of reference page would identify it.
```

## 5. Role of each entity

```
For the topic "[topic]" with main entity [main entity], classify these entities by role: part or type of it, attribute or measure,
used with or related, person or organization behind it, place, alternative or comparison: [paste list].
```

## 6. Find missing entities

```
Here are the entities I have mapped for "[topic]": [paste]. What important entities are missing that an expert would expect,
and why does each one matter? Only list things you are confident exist.
```

## 7. Explain an entity in a self contained passage

```
Write a clear, self contained explanation of [entity] for a page about [topic], in 3 to 4 sentences for [audience].
Say what it is, why it matters for [main entity] and one practical detail. Plain language, no hype.
```

## 8. Section plan from core entities

```
Here are the Main and Core entities for my page about "[topic]" with their importance scores: [paste].
Suggest an H2 and H3 outline where each core entity is explained in the right place, in the order a reader needs them.
```

## 9. Compare two main entities

```
My page compares [entity A] and [entity B]. List the attributes readers compare them on (for example taste, price, caffeine),
and draft a comparison table with honest, checkable rows. Mark any value I must verify.
```

## 10. Check my coverage

```
Here is my page text: [paste]. Here are the entities I expect it to cover: [paste list]. For each entity, say whether the page
does not mention it, mentions it, explains it or gives it its own section. Be strict.
```

## 11. Read an AI answer for entities

```
Here is an AI answer to "[topic]": [paste]. List every entity it names, in order. Which of these are missing from my Entity Map: [paste names]?
```

## 12. Why AI answers skip my brand

```
AI answers about "[topic]" name these brands and sources: [paste]. My business is [what you do]. What do those sources do that makes them
easy to name, and what could we do on and off our site to be named too?
```

## 13. Organization markup draft

```
Draft Organization JSON-LD for my business: name [name], url [url], logo [logo URL], official profiles [list], address [address], email [email].
Use only the facts I gave you. Leave out any property I did not give a value for.
```

## 14. Author page outline

```
Draft an author page outline for [name], who writes about [topics]. Include a short bio, real credentials, experience,
links to profiles and a list of articles. Mark every detail I must fill in myself instead of inventing it.
```

## 15. sameAs URL check

```
Here are entities and the reference URLs I plan to use as sameAs: [paste]. For each, tell me what I should check to confirm the page
is about exactly this entity, and flag any that look like a different thing with the same name.
```

## 16. Entity based FAQ

```
Write 6 FAQ questions and short answers for a page about "[topic]", each built around one of these entities: [paste core entities].
Keep each answer to 2 or 3 factual sentences and mark anything I need to verify.
```

## 17. Quarterly entity review

```
Here is my Entity Map for "[topic]" from [old date]: [paste] and the entities named in today's top results and AI answers: [paste].
What is new, what dropped out and what should I change on my page?
```

## 18. Workflow 1 of 5: brief the assistant

```
You are my entity SEO strategist. My business: [what you sell]. Audience: [who]. Topic: [topic]. Main entity: [main entity].
My page: [URL or planned]. Confirm, then wait for the competitor text.
```

## 19. Workflow 2 of 5: extract entities

```
Here are the headings and key paragraphs of the top 5 results: [paste]. List every entity they name, with type, role and
how many of the 5 pages mention it, as rows I can paste into Excel (tab separated).
```

## 20. Workflow 3 of 5: group and rank

```
Here are my Entity Map rows with importance scores and tiers: [paste]. Group the Main and Core entities into page sections,
and flag any entity that seems wrongly classified, with the reason.
```

## 21. Workflow 4 of 5: the gaps

```
Here is my current page text: [paste]. Using the groups above, list each Core entity my page does not explain,
and for each one write a 3 sentence explanation I can adapt, with the first hand detail I should add from my own experience.
```

## 22. Workflow 5 of 5: brief for Excel

```
Write the brief as rows with tabs between label and text, ready to paste into my Page Plan: What the page is about in one sentence,
Entities to add or explain, Original detail only we can add, Questions the page must answer, Internal links to and from. Then give an H2 outline.
```
