# Search Intent: AI prompt pack

From Brandella Journal, free to use. Full guide: https://brandella.in/resources/seo-aeo-assets/search-intent/

Replace the parts in [square brackets] before you paste a prompt into ChatGPT, Claude or Gemini. Always check the output against real data.

## 1. Classify intent with reasons

```
Act as a senior SEO strategist. Classify each query by search intent (informational, commercial, transactional, navigational)
and add a local flag where people want a place nearby. For each one give a confidence (high, medium, low) and a one line reason.
Mark queries that probably have mixed intent. Queries: [paste list]
Return a table I can paste into Excel.
```

## 2. Read a SERP I describe

```
Here are the top 10 results I saw for "[query]" in [country]: [paste titles and URLs].
Features above the results: [AI Overview, local pack, shopping, People Also Ask].
Count the results by type (guide, list or comparison, product or tool page, brand page), name the dominant format,
describe the shared content angle and say how clear the intent is.
```

## 3. Find the content angle of the winners

```
These are the titles and meta descriptions of the top 10 results for "[query]": [paste].
What angle do most of them share (freshness, price, beginner, expert, local, speed)? What angle is missing that a better page could own?
```

## 4. Mixed intent planner

```
The query "[query]" shows a mixed SERP: [describe the split, for example 5 guides and 5 comparison lists].
Suggest one page outline that serves the dominant intent first and the secondary intent in its own section.
Then say when it would be better to build two separate pages instead.
```

## 5. Split a page that serves several intents

```
My page [URL] currently targets these queries: [paste queries with their intent].
Group them by intent. Recommend which group the page should keep, which groups need a new page,
and the internal links between them. Give a title and slug for each new page.
```

## 6. Know Simple check

```
For each query below, say whether most people would agree on a correct answer that fits in 1 or 2 sentences or a short list.
Mark those as quick answer queries and suggest what extra value a page could give beyond the short answer: [paste list]
```

## 7. Answer first block for an intent

```
Write a 40 to 60 word opening for a page targeting "[query]" with [intent] intent.
It must answer the query fully on its own, in plain language, then hint at the deeper help the page gives.
No fluff, no claims I cannot back up.
```

## 8. Commercial intent page outline

```
The query "[query]" rewards [best of list or comparison] pages. Write an outline for one that helps a buyer decide:
selection criteria, how we tested or chose, a comparison table, who each option suits, and an honest verdict.
My business sells [what you sell], so note where disclosure is needed.
```

## 9. Fan out questions behind a query

```
A person asks an AI assistant "[query]". List 12 follow up questions the system might also need to answer to give
a complete response (subtopics, comparisons, costs, steps, risks). Mark which ones my page [URL] already answers: [paste page headings].
```

## 10. Transactional page checklist

```
For the transactional query "[query]", list what the page must show above the fold for a ready buyer
(price, stock, delivery, trust, options, call to action) and what can go lower. Compare with my page: [paste page summary].
```

## 11. Navigational and brand query audit

```
These queries include my brand [brand]: [paste list]. For each, say which page should rank (home, login, pricing, reviews, contact)
and whether my site has a clear page for it. Flag any brand query where a third party site would likely outrank me.
```

## 12. Local intent check

```
Which of these queries suggest the searcher wants a place nearby or a local provider? [paste list]
For each local one, say whether I need a location page, a Business Profile update or both. I serve [cities].
```

## 13. Rebuild brief for a mismatched page

```
My page [URL] is a [current page type], but the SERP for "[query]" rewards [recommended page type] with this angle: [angle].
Write a rebuild brief: new title, H2 outline, what to keep, what to move to another page, the answer first block, and FAQs.
```

## 14. Intent drift check

```
Last quarter the top 10 for "[query]" was: [paste]. Today it is: [paste].
Describe how the intent or format changed, what likely caused it, and what my page [URL] should change.
```

## 15. Long conversational query mapping

```
Here are long, conversational questions from my site search, support chats and Search Console: [paste].
For each, give the short query it maps to, the intent, and whether it deserves its own page, a section or a FAQ answer.
```

## 16. Signal words for my niche

```
My niche is [niche] in [country]. List words and short phrases that signal each intent in this niche:
transactional, commercial, informational, navigational (my brands are [brands]) and local (my cities are [cities]).
Keep each phrase to 1 to 3 words so I can paste them into my Intent Signals tab.
```

## 17. Funnel balance review

```
Here are my queries with their dominant intent and business value: [paste table].
Is my plan balanced across learn, compare and buy? Which stage is missing pages, and which 5 pages would fix that first?
```

## 18. Workflow 1 of 5: brief the assistant

```
You are my search intent analyst. My business: [what you sell]. Audience: [who]. Country and language: [market].
My brands: [brands]. Goal: [leads, sales or readers]. Confirm you understand, then wait for the next step.
```

## 19. Workflow 2 of 5: first guess

```
Here are my queries: [paste list]. Give each a first intent guess (informational, commercial, transactional, navigational),
a local flag and a one line reason. Mark the ones you are least sure about.
```

## 20. Workflow 3 of 5: correct with real SERPs

```
Here are my notes from the real results for each query (counts by type, top format, angle, AI Overview, local pack): [paste].
Correct your first guesses where the results disagree, and show the dominant intent, clarity and any secondary intent.
```

## 21. Workflow 4 of 5: judge my pages

```
Here is the page I use for each query and what it is today: [paste query, URL, page type].
Rate each as Match, Close, Mismatch or No page yet against the recommended format, and flag URLs that serve more than one intent.
```

## 22. Workflow 5 of 5: fix plan for Excel

```
Turn everything above into a fix plan table I can paste into my workbook, with tabs between columns:
Query, Dominant intent, Recommended page type, Page fit, Recommended action, Target URL, Priority (Fix now, Next, Later).
Sort by priority, then by business value.
```
