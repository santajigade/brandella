# Internal Linking: AI prompt pack

From Brandella Journal, free to use. Full guide: https://brandella.in/resources/seo-aeo-assets/internal-linking/

Replace the parts in [square brackets] before you paste a prompt into ChatGPT, Claude or Gemini. Always check the output against real data.

## 1. Link ideas for a new page

```
I just published "[title]" at [URL] about "[focus keyword]". Here are my other pages with title and URL: [paste list].
Suggest the 5 most relevant pages that should link to the new page. For each, give a descriptive anchor and the kind of
sentence where the link fits naturally. Only use pages from my list.
```

## 2. Rescue an orphan page

```
This page has no internal links: [URL, title, summary]. Here are pages in the same topic: [paste titles and URLs].
Which 3 pages should link to it, with what anchor, and where in each page? If none fit, say whether I should merge it into another page.
```

## 3. Rewrite generic anchors

```
These internal links use generic anchors: [paste source URL, target URL, anchor, and the sentence around it].
Rewrite each anchor so it describes the target page in 2 to 6 words, and rewrite the sentence if needed so it reads naturally.
```

## 4. Anchor variations

```
Write 8 natural anchor text variations for links to my page about "[topic]" ([URL]). Mix the topic, a question, a benefit
and a partial phrase. Keep each under 7 words. No keyword stuffing.
```

## 5. Hub page link list

```
My hub page "[hub title]" covers [topic]. These articles belong to the cluster: [paste titles and URLs].
Write a short, useful section for the hub that links to every article with a descriptive anchor and one line on what each answers.
```

## 6. Find missing cluster links

```
Here are the pages in my "[cluster]" cluster and the links between them (source, target): [paste]. Which pages are not
linked from the hub, which do not link back, and which pairs of articles should link to each other? Give a table.
```

## 7. Contextual link spots

```
Here is the text of my article: [paste]. Here are pages I could link to: [titles and URLs]. Find the 3 best sentences
in the article to add a link, with the anchor words to use from that sentence. Do not add new sentences unless needed.
```

## 8. Reduce click depth

```
These pages are 5 or more clicks from my home page: [paste URLs and titles]. My hub and category pages are: [paste].
Suggest where each deep page should be linked from so it ends up 3 clicks or less from the home page.
```

## 9. Fix links to redirects

```
Here are internal links that point to redirected URLs, with the final URL for each: [paste source, old target, final target].
Give me a find and replace list per source page, and point out any old URL that should be removed instead.
```

## 10. Broken link replacements

```
These internal links point to deleted pages: [paste source URL, broken URL, anchor]. Here are my live pages: [paste titles and URLs].
Suggest the best live replacement for each broken link, or say remove it if nothing fits.
```

## 11. Product links from articles

```
My article "[title]" helps readers with [problem]. My related products or services are: [paste]. Suggest 2 natural places
to link to the most relevant offer, with honest anchors that describe the product, not a hard sell.
```

## 12. Related articles section

```
Here are my articles with title, URL and topic: [paste]. For the article "[title]", choose the 3 best related articles and
write a one line teaser for each that makes the reader want to click. Explain why each is related.
```

## 13. Internal link plan for a new cluster

```
I am building a cluster on "[topic]" with a hub and these planned articles: [list]. Draw the link plan: which page links to
which, with anchor ideas, so every article is linked from the hub, links back, and links to 1 or 2 siblings.
```

## 14. Audit my navigation

```
Here is my main menu and footer: [paste links and labels]. My most important pages by business value are: [list].
Which important pages are missing from the menu or hubs, and which menu labels are unclear?
```

## 15. Explain my crawl

```
Here are summary numbers from my internal link audit: [paste Dashboard key numbers]. Explain in plain words what is most
wrong with my internal linking, what to fix first, and what I can safely ignore.
```

## 16. Merge or link decision

```
These two pages cover similar topics: [URL A, title, summary] and [URL B, title, summary]. Should I merge them, or keep both
and link between them? If I keep both, how should each page link to the other and with what anchor?
```

## 17. Check links for AI search

```
Here is the opening of my page about "[topic]" and the internal links in it: [paste]. Do the links and anchors make clear
what each linked page answers? Suggest changes so a reader, or an AI system summarising the page, can follow the topic.
```

## 18. Workflow 1 of 5: brief the assistant

```
You are my internal linking editor. My site: [site], about [topic], for [audience]. My clusters and hub pages: [paste].
Rules: links go in the body text where they help the reader, anchors are descriptive and 2 to 6 words, no generic anchors,
no exact match stuffing, only real pages from my lists. Confirm, then wait for my data.
```

## 19. Workflow 2 of 5: the Page Inventory rows

```
Here are the Page Inventory rows for my "[cluster]" cluster: URL, title, focus keyword, impressions, position, content links in,
content links to add, linked from hub, priority and fixes: [paste]. Summarise the 3 biggest linking problems in this cluster.
```

## 20. Workflow 3 of 5: link ideas

```
Here are the titles and a short summary of every page in the cluster plus my top pages by traffic: [paste]. Suggest up to 12 new
links that fix the problems you found. For each: source URL, target URL, anchor and the sentence where it fits.
```

## 21. Workflow 4 of 5: pressure test

```
Review your 12 link ideas. Remove any that are not truly relevant, that use a weak or repeated anchor, or that would put too many
links in one paragraph. Keep the best 8 and explain each choice in one line.
```

## 22. Workflow 5 of 5: rows for Excel

```
Turn the best 8 links into rows with tabs between columns for my Link Planner: Source URL, Target URL, Proposed anchor,
Placement (Early in the body, In the body, List or table, or Navigation or template), Status (Planned), Date added (blank),
Notes (the reason for the link).
```
