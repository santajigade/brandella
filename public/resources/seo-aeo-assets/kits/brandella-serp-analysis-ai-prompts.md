# SERP Analysis: AI prompt pack

From Brandella Journal, free to use. Full guide: https://brandella.in/resources/seo-aeo-assets/serp-analysis/

Replace the parts in [square brackets] before you paste a prompt into ChatGPT, Claude or Gemini. Always check the output against real data.

## 1. Read a results page

```
Here are the page one results for "[keyword]" in [country] on [device], with position, title, site type, page format and main angle: [paste].
Summarise in 5 bullets what searchers want, which format wins, and what every result has in common.
```

## 2. Implied intent check

```
Based on these page formats for "[keyword]": [paste formats], is the intent informational, commercial, transactional or navigational?
If the results are mixed, explain which needs they serve and which one my page for [business] should serve.
```

## 3. Find the weak results

```
Here are page one results with update date, named author, first hand experience and referring domains: [paste].
Rank them from easiest to hardest to beat and explain each in one line. Do not guess data I did not give you.
```

## 4. Common ground and missing angles

```
Here are the H2 headings of the top 5 pages for "[keyword]": [paste]. List the subtopics every page covers (the basics I must include),
the subtopics only one or two cover, and useful subtopics none of them cover.
```

## 5. Angle only we can offer

```
The top results for "[keyword]" all take these angles: [paste]. My business is [what you do] and we have [data, experience, customers, tools].
Suggest 5 angles only we could write, each with one sentence on the proof we would show.
```

## 6. First hand detail list

```
I am writing about "[keyword]" for [audience]. List 15 kinds of first hand detail that would make the page clearly better than a generic article,
such as photos, measurements, test results, mistakes we saw and customer questions.
```

## 7. Featured snippet answer

```
Write a direct answer of 2 to 3 sentences to the question "[question]" that could sit right under a question heading.
Then suggest the heading itself and one follow up sentence that leads into the detail.
```

## 8. People also ask to sections

```
Here are the People also ask questions for "[keyword]": [paste]. Group them into page sections, suggest an H2 for each group
and say which questions deserve their own page instead.
```

## 9. SERP feature plan

```
Page one for "[keyword]" shows these features: [AI Overview, featured snippet, People also ask, videos, images, local pack, products].
For a [page format] page from [business], what should the page include to have a chance in each feature?
```

## 10. Compare AI answer links with rankings

```
The AI answer for "[keyword]" links these pages: [paste URLs]. The organic top 10 is: [paste URLs].
Which linked pages are not in the top 10, and what do they do differently, judging from their content: [paste summaries]?
```

## 11. Title ideas from the SERP

```
Here are the titles of the top 10 results for "[keyword]": [paste]. Suggest 5 titles for my page that match the intent,
stand out from these, stay under 60 characters and promise only what the page delivers.
```

## 12. Meta description from the SERP

```
Here are the snippets shown for the top 5 results for "[keyword]": [paste]. Write 3 meta descriptions for my page
that are specific, mention what makes it different and stay under 155 characters.
```

## 13. Is this keyword worth it?

```
Here is my SERP summary for "[keyword]": verdict [verdict], score [score], dominant format [format], beatable results [n],
SERP features [list], my status [status]. Should I target it now, choose a narrower version or skip it? Suggest 3 narrower versions.
```

## 14. Narrower long tail versions

```
"[keyword]" is dominated by [site types]. Suggest 10 narrower, more specific versions that a smaller site
like mine ([business]) could realistically win, and say which format each would need.
```

## 15. Upgrade plan for a page already on page one

```
My page "[title]" ranks [position] for "[keyword]". The pages above it: [paste format, angle and headings].
Mine: [paste headings]. Give me an upgrade plan in priority order, keeping what already works.
```

## 16. Writer handover note

```
Turn this SERP analysis into a short note for a writer: [paste summary and weak spots]. Include the format, the must cover basics,
the angle, the first hand detail to gather and 3 things not to copy from competitors.
```

## 17. Quarterly SERP change review

```
Here is my SERP log for "[keyword]" from [old date]: [paste] and today: [paste]. What changed in formats, sites, features and AI answers,
and what should I change on my page?
```

## 18. Workflow 1 of 5: brief the assistant

```
You are my SEO content strategist. My business: [what you sell]. Audience: [who]. Country and device: [market].
Target keyword: [keyword]. My current page: [URL or none]. Confirm, then wait for my SERP data.
```

## 19. Workflow 2 of 5: patterns in my log

```
Here are my SERP Log rows for the keyword with position, site type, format, angle, update date, author, first hand experience and weak spots: [paste].
Summarise the patterns: winning format, typical site, freshness and what the Strong results share.
```

## 20. Workflow 3 of 5: the gaps

```
Here are the H2 headings of the 3 Strong results and 3 Beatable results: [paste]. List the basics every page covers,
what the Strong results do better, and what none of them do.
```

## 21. Workflow 4 of 5: our angle

```
Using what you know about my business, choose the single best angle for my page and list the first hand proof we must gather.
Explain in 2 sentences why it beats the current page one.
```

## 22. Workflow 5 of 5: brief for Excel

```
Write the brief as rows with tabs between label and text, ready to paste into my Page Plan:
Our angle in one sentence, Original value only we can add, Questions the page must answer, Format we will build, Target URL,
Pages that will link to it. Then give an H2 outline.
```
