# AI Overview Targeting: AI prompt pack

From Brandella Journal, free to use. Full guide: https://brandella.in/resources/seo-aeo-assets/ai-overview-targeting/

Replace the parts in [square brackets] before you paste a prompt into ChatGPT, Claude or Gemini. Always check the output against real data.

## 1. Read an AI Overview

```
Here is the AI Overview text for "[query]" and the list of sources it cites: [paste].
Summarise what the overview answers, which sub questions it covers, what each cited source contributes,
and what it leaves out or answers vaguely. Do not add facts of your own.
```

## 2. Map fan out sub questions

```
For the query "[query]", here are People also ask questions, related searches, AI Mode follow ups and
Search Console queries for my page: [paste]. List 6 to 10 distinct sub questions in the order a reader would ask them,
with a type for each (definition, how to, comparison, cost, problem, example, safety, next step).
```

## 3. Compare my page with cited sources

```
Here is my page outline and opening: [paste]. Here are the headings and key points of the sources cited in the
AI Overview for "[query]": [paste]. List what they cover that I do not, what I cover better, and the 3 changes most likely
to make my page a stronger source.
```

## 4. Write an answer first block

```
Write a 40 to 60 word answer to "[question]" for [reader]. It must answer fully on its own, in plain language,
with the key condition or number if there is one. Then suggest a descriptive heading to put above it.
```

## 5. Turn sub questions into headings

```
Here are sub questions for my page about [topic]: [paste]. Write a descriptive H2 or H3 heading for each, in plain
language with no hyphens, and suggest the best format for each section (paragraph, steps, table or list).
```

## 6. Find original value

```
My business is [business]. The sources cited for "[query]" all say [summary]. Suggest 6 kinds of original value we could
add (our own data, a test, photos, a worked example, expert input, customer results), what each needs and how long it takes.
```

## 7. Fact check list

```
Here is the text of my page: [paste]. List every fact, number, rule, price, date and named product, with what I must
verify and the kind of official source to check. Do not confirm anything yourself.
```

## 8. Check eligibility settings

```
Here is the head section and robots meta of my page, my robots.txt rules and any data-nosnippet markup: [paste].
Tell me in plain words whether anything stops Google from indexing the page or showing a snippet of the main answer.
```

## 9. Structured data matches the page

```
Here is my page text and its JSON-LD: [paste both]. List every structured data value that does not match the visible
text, is missing from the page, or could mislead. Suggest the corrected values.
```

## 10. Section for a missing sub question

```
My page about [topic] does not answer "[sub question]". Write a short section (120 to 200 words) that answers it clearly,
with a heading, using only these facts I have checked: [paste facts]. Mark any gap where I need more information.
```

## 11. Make an image or video plan

```
For my page about [topic], suggest 3 original images or one short video that would help readers more than text,
what each should show, and alt text for each image.
```

## 12. Internal links for an answer page

```
Here are my pages with titles: [paste list]. For the page "[title]", suggest 3 pages that should link to it and the
sentence where each link fits, with descriptive anchor text.
```

## 13. Write a clear author box

```
Write a short author and reviewer note for my page about [topic]. Author: [name, role, experience]. Reviewer: [name,
role]. Keep it factual and under 60 words, and say what first hand experience they bring.
```

## 14. Explain why a competitor is cited

```
The AI Overview for "[query]" cites [competitor page] and not mine. Here is their outline and mine: [paste both].
Give the most likely reasons in plain words, based only on what I pasted, and the changes I can make.
```

## 15. Review the Action Plan results

```
Here is my Action Plan export with fix type, date, AI impressions before and after and citations before and after: [paste].
Which kinds of fixes worked best? What should we do more of next month and what should we stop?
```

## 16. Explain AI search visibility to a manager

```
Write a short update for my manager on our AI Overview work. Data: [paste dashboard numbers]. Explain where we are cited,
which pages were blocked and fixed, what we changed and the plan for next month. No jargon.
```

## 17. Monthly recheck summary

```
Here are my priority queries with last month's and this month's AI Overview and citation results: [paste].
List the queries where we gained or lost a citation, what changed on those pages, and what to check next.
```

## 18. Workflow 1 of 5: brief the assistant

```
You are my AI search visibility assistant. My site: [site]. Readers: [readers]. Goal: [goal].
Rules: never invent facts, quote only what I paste, plain language, no hyphens in headings. Confirm, then wait for the next step.
```

## 19. Workflow 2 of 5: read the AI Overview

```
Query: "[query]". Here is the AI Overview text and the cited sources with their headings: [paste].
Tell me what it answers, what each source contributes and what is missing.
```

## 20. Workflow 3 of 5: fan out map

```
Here are People also ask, related searches and AI Mode follow ups: [paste]. Here is my page outline: [paste].
List 6 to 10 sub questions and mark each Yes, Partly or No for my page, as tab separated rows I can paste into my Fan Out Map:
Main query, Sub question, Type, Found in, Covered on the page?
```

## 21. Workflow 4 of 5: plan the fixes

```
My Page Audit shows these gaps with weights: [paste]. Using the comparison and the fan out map, put the fixes in order
of impact, with the facts I must verify for each.
```

## 22. Workflow 5 of 5: draft and log

```
Draft the answer first block and the new sections for the top 2 fixes, in my voice, with short paragraphs.
Then write one tab separated line per fix for my Action Plan: Page URL, Fix, Owner.
```
