# Blog Briefs: AI prompt pack

From Brandella Journal, free to use. Full guide: https://brandella.in/resources/seo-aeo-assets/blog-briefs/

Replace the parts in [square brackets] before you paste a prompt into ChatGPT, Claude or Gemini. Always check the output against real data.

## 1. Read a results page

```
Here are the titles, headings and formats of the top 5 results for "[keyword]": [paste].
An AI Overview [does or does not] show. Tell me the search intent, the format that ranks, what every result covers
and what none of them covers well. Do not guess anything I did not give you.
```

## 2. Find the sub questions

```
For the topic "[topic]", here are People also ask questions, related searches and AI Overview text: [paste].
Group them into 6 to 10 distinct sub questions a reader has, in the order they would ask them.
Mark which ones need a table, steps or an example.
```

## 3. Choose the information gain

```
My business is [business] and my readers are [readers]. The top results for "[keyword]" all cover [list].
Suggest 5 things only we could add (data we have, tests we can run, experts we know, templates, customer stories),
how long each would take, and which one would help the reader most.
```

## 4. Pick the format and length band

```
Here are the top 3 results for "[keyword]" with format and approximate word count: [paste].
Which format should my article use and why? Suggest a sensible length range, and say which parts of the topic
deserve the most words. Do not suggest padding.
```

## 5. Write 10 working titles

```
Write 10 working titles for an article about [topic] for [reader] with the focus keyword "[keyword]" near the start.
Under 60 characters each, honest, no clickbait, and each should promise what the article really delivers.
```

## 6. Write the answer first block

```
Write a 40 to 60 word answer to "[main question]" for [reader]. It must fully answer the question on its own,
in plain language, with no filler. Then list the 3 details the rest of the article should add.
```

## 7. Outline in Outline Bank columns

```
Create an outline for "[title]" with these columns separated by tabs: Order, Level (H2, H3 or FAQ), Heading,
Question it answers, Points and entities to cover, Section format, Words planned, Source to use.
Use these sub questions: [paste]. Keep the total near [target] words. Headings must be descriptive, no hyphens.
```

## 8. Entities and terms to cover

```
For an article on "[topic]", list the people, organisations, products, terms and concepts a complete answer
should mention, grouped by section of this outline: [paste outline]. Flag any term a beginner would need explained.
```

## 9. Sources for each section

```
Here is my outline: [paste]. For each section, suggest the type of official or primary source a writer should use
(government site, standards body, product documentation, study) and what to verify. Do not invent URLs.
```

## 10. Internal links plan

```
Here are my existing articles with titles and URLs: [paste list]. For a new article "[title]", suggest 3 to 5 pages
it should link to, with anchor text and the section where each link fits, and 2 pages that should link to it.
```

## 11. Check for keyword overlap

```
Here is my list of planned and published articles with their focus keywords: [paste]. Find pairs that target the
same search intent, and for each pair suggest whether to merge them or give one a different keyword and angle.
```

## 12. FAQ from real questions

```
Here are questions from customers, support tickets and People also ask for [topic]: [paste].
Pick the 4 most useful that the main sections do not already answer, and write a one line note on what each answer needs.
```

## 13. Brief for an expert interview

```
I will interview [expert role] for an article on "[topic]". Write 8 questions that would give us original insight
the top results lack, and 3 follow up questions for each answer that sounds generic.
```

## 14. Check a draft against the brief

```
Here is the brief: [paste brief text and outline]. Here is the draft: [paste draft].
List where the draft misses a section, skips a question, lacks the information gain, adds filler or makes a claim
without a source. Be specific and quote the lines.
```

## 15. Fact check list for an AI assisted draft

```
Here is an AI assisted draft: [paste]. List every fact, number, date, price, rule and named product in it, with what
I must verify and where. Do not confirm anything yourself; give me the list to check.
```

## 16. Title and meta description

```
The article "[title]" targets "[keyword]" and covers: [summary]. Write 5 title options under 60 characters and
3 meta descriptions of 120 to 160 characters that promise only what the article delivers.
```

## 17. Turn a brief into a writer email

```
Turn this brief into a short, friendly email to a freelance writer: [paste brief]. Keep every requirement, the
deadline and the information gain, and ask them to confirm they can meet the date.
```

## 18. Monthly content plan review

```
Here is my Brief Pipeline export with score, priority, status, writer and due status: [paste].
Which briefs should we write next month within [hours] writing hours, which should we drop or merge, and why?
```

## 19. Workflow 1 of 5: brief the assistant

```
You are my content brief assistant. My site: [site]. Readers: [readers]. Goal: [leads, sales or readers].
Rules: one focus keyword per article, never invent facts or sources, plain language, no padding, every brief needs
information gain. Confirm you understand, then wait for the next step.
```

## 20. Workflow 2 of 5: read the results page

```
Focus keyword: "[keyword]". Here are the top 5 results (title, headings, format) and the AI Overview text: [paste].
Tell me the intent, the format to use, what everyone covers and the gaps.
```

## 21. Workflow 3 of 5: sub questions and information gain

```
Here are People also ask questions and related searches: [paste]. Map 6 to 10 sub questions in reading order,
then choose the single best information gain we can offer from this list of what we have: [data, experts, tests].
```

## 22. Workflow 4 of 5: outline

```
Write the outline as tab separated rows: Order, Level, Heading, Question it answers, Points and entities to cover,
Section format, Words planned, Source to use. Start with an answer first section. Total about [target] words.
```

## 23. Workflow 5 of 5: brief text and self check

```
Write the final brief: title, focus keyword, reader, goal, length band, answer first, information gain, links and
sources. Then check it against these rules and list anything missing: 11 fields filled, a question for every section,
a source for every section, no padding, no keyword planned twice.
```
