# Content Refreshes: AI prompt pack

From Brandella Journal, free to use. Full guide: https://brandella.in/resources/seo-aeo-assets/content-refreshes/

Replace the parts in [square brackets] before you paste a prompt into ChatGPT, Claude or Gemini. Always check the output against real data.

## 1. Diagnose a page that lost clicks

```
Here are Search Console numbers for [URL] for two periods of the same length:
clicks [previous] to [recent], impressions [previous] to [recent], average position [previous] to [recent].
An AI Overview [does or does not] show for the main query "[query]". Explain the most likely reason for the change
(ranking drop, CTR drop, lower demand or mixed) and what to check next. Do not guess numbers I did not give.
```

## 2. Compare queries before and after

```
Here are the queries for [URL] with clicks and position for two periods: [paste table]
Show which queries lost the most clicks, which lost position, and which are new. Group them by intent
and tell me which sections of the page should change.
```

## 3. Compare my page with today's top results

```
Here is my page outline: [paste headings]. Here are the headings of the top 3 results for "[query]": [paste].
List the subtopics, questions and formats the top results cover and I do not, and what my page offers that they lack.
```

## 4. Find outdated facts

```
Here is the text of my page from [date]: [paste text]. List every fact, number, price, rule, product name,
date and link that may have changed since then, with what I should check and where (official sources first).
Do not state new facts yourself; give me the list to verify.
```

## 5. Answer first block for an AI Overview query

```
The query "[query]" shows an AI Overview. Here is my current opening: [paste]. Write a clear 40 to 60 word answer
that fully answers the query on its own, in plain language, then suggest what depth should follow it
that a summary cannot give.
```

## 6. Rewrite the title and description

```
My page "[title]" for the query "[query]" lost clicks while impressions stayed the same. Here are the titles of the
top results: [paste]. Write 5 better titles (under 60 characters) and 3 meta descriptions (120 to 160 characters)
that match the intent and promise only what the page delivers.
```

## 7. Add first hand experience

```
My page about [topic] reads like every other result. Ask me 8 questions about my real experience, data or customer
examples on this topic. After I answer, suggest where each answer should go on the page.
```

## 8. Merge two overlapping pages

```
These two pages target the same main query "[query]": Page A [URL and outline], Page B [URL and outline].
Recommend which URL to keep, what content to move from the other, and the redirect to add. Keep the strongest
sections of both.
```

## 9. Decide merge, improve or leave

```
This page gets very little traffic: [URL, topic, clicks, links, conversions]. Decide whether to merge it into
[related page], improve it or leave it as it is, and explain the reason in three lines.
```

## 10. Seasonal refresh plan

```
These pages are seasonal: [paste pages with peak months]. Suggest the month to refresh each one so the update is live
before demand rises, and what usually needs updating each year.
```

## 11. Write a change log

```
Here is the old version and the new version of my page: [paste both or describe the changes].
Write a short change log (what changed and why) and say whether the change is substantial enough to update the date.
```

## 12. Refresh brief for a writer

```
Write a refresh brief for [URL]. Diagnosis: [diagnosis]. Main query: [query]. Business goal: [goal].
Include what to keep, what to update, what to add, the answer first block, FAQs, internal links to [pages]
and what not to change (URL, sections that still rank).
```

## 13. Internal links for a refreshed page

```
I refreshed [URL] about [topic]. Here is a list of my other pages with titles: [paste list].
Suggest 5 pages that should link to it, the sentence where the link fits and descriptive anchor text.
```

## 14. FAQ from real questions

```
Here are questions from my support inbox, comments and People Also Ask for [topic]: [paste].
Pick the 5 most useful for my page, merge duplicates and write short, accurate answers I can check.
```

## 15. Update a statistics section

```
My page uses these statistics: [paste with sources and years]. For each one, tell me whether it is likely outdated,
what kind of source would have a newer figure, and how to word it if I cannot find a newer one.
```

## 16. Refresh results review

```
Here are my refreshes with refresh type, date and clicks 28 days before and after: [paste table].
Which refresh types worked best? What patterns do you see, and what should I change in my process?
```

## 17. Explain refresh work to a manager

```
Write a short update for my manager about our content refresh work. Data: [paste dashboard numbers].
Explain which pages were falling and why, what we refreshed, early results and the plan for next month.
```

## 18. Workflow 1 of 5: brief the assistant

```
You are my content refresh assistant. My site: [site and audience]. Goal: [leads, sales or readers].
Rules: keep URLs, never invent facts, change the date only for substantial updates. Confirm you understand,
then wait for the next step.
```

## 19. Workflow 2 of 5: diagnose

```
Page: [URL and title]. Main query: [query]. Clicks [previous] to [recent], impressions [previous] to [recent],
position [previous] to [recent], AI Overview: [yes or no]. Diagnose the decay type and what it means for this page.
```

## 20. Workflow 3 of 5: compare

```
Here are the headings and key points of the top 3 results and the AI Overview text for "[query]": [paste].
Here is my page outline: [paste]. List the gaps, the outdated parts and what my page does better.
```

## 21. Workflow 4 of 5: plan the refresh

```
Using the diagnosis and the comparison, write a refresh plan in four lists: keep, update, add and remove.
Mark each item with the facts I must verify and the source to check.
```

## 22. Workflow 5 of 5: draft and log

```
Draft the new and updated sections from the plan, in my voice, with short paragraphs. Then write one line for
my Refresh Queue with these columns separated by tabs: URL, What changed, Substantial change? (Yes or No).
```
