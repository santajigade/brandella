# Featured Snippets: AI prompt pack

From Brandella Journal, free to use. Full guide: https://brandella.in/resources/seo-aeo-assets/featured-snippets/

Replace the parts in [square brackets] before you paste a prompt into ChatGPT, Claude or Gemini. Always check the output against real data.

## 1. Pick the right snippet format

```
Here is a search query: "[query]". Here is what the current featured snippet shows (or "none"): [paste].
Tell me which format fits best (paragraph, ordered list, unordered list or table) and why, in two sentences.
If a snippet already shows, tell me to match its format unless there is a strong reason not to.
```

## 2. Write a paragraph answer block

```
Write a featured snippet style answer to "[question]" for [reader]. Rules: 40 to 55 words, 2 or 3 sentences,
start with the subject of the question, plain language, no intro, no fluff, include the key number or condition if there is one.
Then suggest a question heading to put right above it.
```

## 3. Write a numbered steps block

```
Turn this process into an ordered list for a featured snippet: [paste process]. Rules: 4 to 8 steps, one short step per line,
start each step with a verb, about 12 words or fewer per step, keep the real order. Add a heading that asks the question "[query]".
```

## 4. Write a bulleted list block

```
Write an unordered list that answers "[query]" for [reader]. Rules: 4 to 8 items, one per line, short items,
the most important item first. Use only these facts I have checked: [paste facts].
```

## 5. Turn a comparison into a table

```
Turn this comparison into a small HTML table for the query "[query]": [paste notes]. Rules: a header row,
3 to 5 rows, 2 or 3 columns, cells of 3 words or fewer where possible. Then give me the plain HTML.
```

## 6. Trim an answer to length

```
Here is my answer block: [paste]. It must fit [target from the Answer Builder]. Cut it to fit without losing
the key fact. Remove any intro sentence. Show the new version and its word count.
```

## 7. Compare my answer with the current snippet

```
The current featured snippet for "[query]" says: [paste]. My answer block says: [paste].
Which one answers the question more completely and more clearly? List what mine is missing and what mine does better.
Do not add facts of your own.
```

## 8. Find snippet questions in my Search Console data

```
Here are queries from my Search Console Performance report with position and impressions: [paste].
List the questions and question like queries where I rank 1 to 10, grouped by the format a snippet would likely use.
```

## 9. Check snippet controls in my page source

```
Here is the head section of my page, any X-Robots-Tag header and the HTML around my answer: [paste].
Tell me in plain words whether nosnippet, max-snippet or data-nosnippet could stop Google showing my answer as a snippet.
```

## 10. Heading for an answer block

```
Suggest 5 question headings for a section that answers "[query]". Use the words people search, no hyphens,
under 60 characters each. Mark the one closest to the query.
```

## 11. Key term early rewrite

```
Rewrite the first sentence of this answer so it starts with the key term "[key term]" and still reads naturally: [paste].
Keep the meaning and the length the same.
```

## 12. Follow up depth after the answer

```
My page answers "[query]" in a short block. Suggest 4 sections that should follow it to give readers a reason to click
and stay: examples, mistakes, a tool, a deeper explanation. One line each.
```

## 13. People also ask answers

```
Here are People also ask questions for "[query]": [paste]. Write a 40 to 55 word answer for each, starting with
the subject of the question. Mark any answer where I need to check a fact.
```

## 14. Video snippet plan

```
The query "[query]" shows a video snippet. Write a plan for a short how to video: the steps, chapter names with
times, a title and a description that answers the query in the first sentence.
```

## 15. Fact check an answer block

```
Here is my answer block: [paste]. List every fact, number, time and rule in it, and the kind of official source
I should check each one against. Do not confirm anything yourself.
```

## 16. Review the Action Plan results

```
Here is my Action Plan export with fix, done date, snippet holder before and after and clicks before and after: [paste].
Which kinds of fixes won snippets or moved clicks? What should we do more of next month and what should we stop?
```

## 17. Explain featured snippet work to a manager

```
Write a short update for my manager. Data: [paste dashboard numbers]. Explain how many snippets show for our queries,
how many we hold, what we fixed, what we won or lost and the plan for next month. No jargon.
```

## 18. Workflow 1 of 5: brief the assistant

```
You are my featured snippet assistant. My site: [site]. Readers: [readers].
Rules: paragraph answers 40 to 55 words in 2 or 3 sentences, lists 4 to 8 short items, tables 3 to 5 rows and 2 or 3 columns,
answer first, plain language, no hyphens in headings, never invent facts. Confirm, then wait for the next step.
```

## 19. Workflow 2 of 5: read the current snippet

```
Query: "[query]". Here is the current featured snippet, its format and the headings of the top 3 results: [paste].
Tell me what the snippet answers, its format and length, and what it leaves out.
```

## 20. Workflow 3 of 5: draft the answer block

```
Using only these facts I have checked: [paste facts], draft an answer block in the same format as the current snippet,
within the length rules, with a question heading above it.
```

## 21. Workflow 4 of 5: test and trim

```
Test your draft against these checks: length fits the format, heading states the question, key term in the first sentence,
answer comes right after the heading, short sentences or items. Fix anything that fails and show the final version.
```

## 22. Workflow 5 of 5: log it

```
Write one tab separated line for my Answer Builder: Query, Key term, Answer format, Heading above the answer, Answer text
(list items separated by " / "). Then one line for my Action Plan: Query, Fix, Owner.
```
