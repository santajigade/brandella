# Title Tag Optimization: AI prompt pack

From Brandella Journal, free to use. Full guide: https://brandella.in/resources/seo-aeo-assets/title-tag-optimization/

Replace the parts in [square brackets] before you paste a prompt into ChatGPT, Claude or Gemini. Always check the output against real data.

## 1. Title options for a page

```
Write 10 title tags for a [page type] about "[focus keyword]" for [audience]. Put the keyword in the first 25 characters, say what makes
the page useful ([what is special]), keep each under 60 characters, use no brackets and promise only what the page delivers.
```

## 2. Shorten a long title

```
This title is [x] characters: "[title]". Write 5 versions under 60 characters that keep the topic at the start and the most
useful promise. Do not add new claims.
```

## 3. Fix a vague title

```
My [page type] has the vague title "[title]". The page is about [what it covers] for [audience]. Write 5 specific titles that say
what the page is, who it is for and why it is useful.
```

## 4. Remove keyword stuffing

```
This title repeats keywords: "[title]". Rewrite it as one natural phrase with "[focus keyword]" once, under 60 characters,
that a person would want to click.
```

## 5. Unique titles for similar pages

```
These pages share the same or nearly the same title: [paste URLs, titles and a one line summary of each]. Write a unique title for
each that says what that page alone offers.
```

## 6. Why did Google rewrite my title

```
My title tag is "[title]". My H1 is "[H1]". Google shows "[shown title]" for the search "[query]". Explain the most likely reasons
Google rewrote it, based on Google's title link guidance, and suggest 3 titles Google would have less reason to change.
```

## 7. Match the title and H1

```
My title is "[title]" and my H1 is "[H1]" on a page about "[focus keyword]". Suggest a title and H1 pair that describe the same
topic in natural words. The H1 may be longer; the title must stay under 60 characters.
```

## 8. Search intent check

```
Here are the titles of the top 10 results for "[query]": [paste]. What do searchers want (guide, list, tool, product, local answer)?
Which words and angles repeat? Suggest 5 titles for my page that fit that intent but stand out.
```

## 9. Angle beyond the AI answer

```
For the search "[query]", an AI Overview already gives a short answer. My page offers [our data, tool, photos, tests, local detail].
Write 5 titles that promise what the summary cannot give, under 60 characters, with no clickbait.
```

## 10. Product title pattern

```
Create a title pattern for my [product type] pages using these fields: [name, key spec, size, material, brand]. Show the pattern and
5 example titles from these products: [paste]. Each under 60 characters, keyword first.
```

## 11. Category title pattern

```
Write title patterns for my category pages ([list categories]) that use the category name first, a useful qualifier such as the
number of products or the main types, and the site name "[site name]" once at the end.
```

## 12. Local page titles

```
Write 5 title tags for my [service] page in [city or area]. Include the service and the place naturally, one reason to choose us
([proof]) and keep each under 60 characters.
```

## 13. Year in the title

```
My title "[title]" includes the year [year]. I updated these parts of the page: [list]. Should the title show a year at all?
If yes, write the updated title; if no, write a timeless version.
```

## 14. Title for a tool or calculator

```
Write 5 titles for my free [tool name] that says what it does in plain words ([input] to [output]), keyword first, under 60 characters.
```

## 15. Translate a title for another market

```
Translate this title for [language and country]: "[title]". Use the words people there really search for "[keyword]", keep the
same promise and keep it under 60 characters. Use the language and script of that page.
```

## 16. Title test idea list

```
Here are 10 Title Lab rows with title, CTR, band average CTR and position: [paste]. For each, suggest one title change worth
testing and the reason, most promising first.
```

## 17. Read my test results

```
Here are my Test Log rows (old title, new title, CTR before and after, position before and after, days live): [paste].
Which changes look like real wins, which are unfair tests, and what should I test next?
```

## 18. Workflow 1 of 5: brief the assistant

```
You are my title tag editor. My site: [site name], about [topic], for [audience]. My site name in titles is "[site name]".
Rules: keyword in the first 25 characters, under 60 characters, no brackets, no keyword repeats, nothing the page does not deliver.
Confirm, then wait for my data.
```

## 19. Workflow 2 of 5: the Title Lab row

```
Here is the Title Lab row for one page: URL, focus keyword, current title, H1, title Google shows, CTR, band average CTR,
position and the fixes in priority order: [paste]. Explain in plain words what is wrong with the current title and why Google
may be rewriting it.
```

## 20. Workflow 3 of 5: ten new titles

```
Here is what the page covers and what makes it special: [paste summary]. Write 10 new titles using different patterns
(keyword: angle, how to, number and proof, question, comparison). Show the character count of each.
```

## 21. Workflow 4 of 5: pressure test

```
Here are the top 5 results for "[query]": [paste titles]. Score each of your 10 titles from 1 to 5 for clarity, honesty,
difference from the results above and fit with my H1 "[H1]". Keep the best 3 and explain why.
```

## 22. Workflow 5 of 5: rows for Excel

```
Turn the best title into a row with tabs between columns for my Test Log: URL, Old title, New title, Date changed ([date]),
Status (Planned), Impressions before, Clicks before, Position before (use my numbers: [paste]), Notes (the reason for the change).
```
