# Competitor Gaps: AI prompt pack

From Brandella Journal, free to use. Full guide: https://brandella.in/resources/seo-aeo-assets/competitor-gaps/

Replace the parts in [square brackets] before you paste a prompt into ChatGPT, Claude or Gemini. Always check the output against real data.

## 1. Find my real search competitors

```
Act as an SEO analyst. My site: [domain]. I sell [what you sell] to [audience] in [country].
Here are the domains that appear on page one for my 10 main keywords: [paste keyword and domains].
Group the domains into business competitors, publishers, template or marketplace sites, forums and review sites.
Recommend the 4 I should track as search competitors and explain why in one line each.
```

## 2. Explain a gap list

```
Here are keyword gap rows from my spreadsheet with gap type, intent, volume, KD and each site's position: [paste].
Summarise the 5 biggest patterns. Which topics does one competitor own? Where am I close to winning?
```

## 3. Why does this competitor win?

```
Here are the headings, word count, media and page type of the page ranking at position [n] for "[keyword]": [paste].
Here is the same for my page: [paste]. List the 7 most likely reasons their page is more useful to searchers,
most important first. Do not guess about backlinks or traffic.
```

## 4. New page or upgrade?

```
For each keyword below I have my ranking URL (or none), the gap type and the best competitor's page type: [paste].
Decide for each: new page, upgrade existing page, merge into another page or skip. Give a one line reason.
```

## 5. Non commodity angle finder

```
The top pages for "[keyword]" all say roughly the same thing: [paste their main points].
Based on my business ([what we do, data we have, experience]), suggest 5 angles only we could write,
such as first hand tests, our own numbers, customer examples or expert opinions.
```

## 6. Brief for a Missing keyword

```
Write a content brief for a new page targeting "[keyword]" ([intent] intent). The best ranking competitor is [URL description].
Include the page type, title, H2 outline, questions to answer, the original value we add, internal links to [our related pages]
and what would make it clearly more useful than the current top 3.
```

## 7. Upgrade plan for a Weak page

```
My page "[title]" ranks at [position] for "[keyword]". The page at position [position] covers: [paste headings].
Mine covers: [paste headings]. List the missing subtopics, outdated parts and weak sections, and give me
an upgrade plan in priority order.
```

## 8. Competitor topic map

```
Here is a list of keywords one competitor ranks for that I do not: [paste]. Group them into 5 to 10 topics,
name each topic, and say which topics fit a business that sells [what you sell] and which to ignore.
```

## 9. Comparison page outline

```
Outline an honest comparison page "[my product] vs [competitor]" for [audience]. Include a short verdict,
a feature table, pricing notes to verify, who each option suits best, and a FAQ. Mark every claim I must fact check.
```

## 10. Alternatives page outline

```
Outline a "[competitor] alternatives" page that is genuinely useful: 6 to 8 options including my product,
who each suits, honest pros and cons, and how to choose. Mark every fact I must verify before publishing.
```

## 11. AI answer test set

```
I sell [what you sell] to [audience]. Write 25 questions buyers might ask an AI assistant before choosing a product like mine,
grouped by stage: problem, solution, comparison, choice. Keep them natural and short.
```

## 12. Analyse an AI answer

```
Here is an AI answer to "[question]" with its linked sources: [paste]. Which brands are mentioned, which sources are linked,
and what does each linked page do well? What would my page at [URL] need to be the clearest source for this answer?
```

## 13. Mentioned but not linked fix

```
AI answers mention my brand for "[question]" but link [competitor URL]. Compare the two pages: [paste both outlines].
Suggest the changes that would make my page the most complete, quotable and trustworthy source on this exact question.
```

## 14. Defend a Strong keyword

```
I rank first for "[keyword]" with [URL]. Competitors are at [positions]. List what I should refresh every quarter
to stay the best result: facts, examples, screenshots, internal links and new follow up questions.
```

## 15. Gap volume by topic summary

```
Here is my gap table with topic, gap type, volume and click upside: [paste]. Build a short summary for my manager:
the 3 topics with the biggest opportunity, what we will do in the next 30 days and the risks.
```

## 16. Skip list sanity check

```
Here are keywords I plan to skip, with intent and business value: [paste]. Challenge my choices.
Which ones might matter more than I think, and why? Be brief.
```

## 17. Quarterly gap review

```
Here are my gap counts and share of clicks from last quarter: [paste] and this quarter: [paste].
What changed, which competitor gained, and which 5 actions should go into next quarter's plan?
```

## 18. Workflow 1 of 5: brief the assistant

```
You are my SEO strategist. My site: [domain]. We sell [what you sell] to [audience] in [country].
My 4 search competitors: [names and domains, with their type]. Goal: [leads, sales or sign ups]. Confirm, then wait.
```

## 19. Workflow 2 of 5: explain the gaps

```
Here are my top 20 Missing, Untapped and Weak keywords with volume, KD, intent and positions: [paste].
Group them by topic and say which competitor leads each topic.
```

## 20. Workflow 3 of 5: why they win

```
For the 5 most valuable gaps, here are the headings and page types of the best competitor pages: [paste].
For each, explain why that page wins and what original value we could add that they cannot.
```

## 21. Workflow 4 of 5: plan the plays

```
For every keyword above, choose one play: new page, upgrade existing page, merge or skip. Give the page type,
a working title and a short readable URL for new pages, and say which existing page to upgrade for the rest.
```

## 22. Workflow 5 of 5: table for Excel

```
Turn the plan into one table with tabs between columns, ready to paste into my Action Plan:
Keyword, Decision (Target, Monitor or Skip), Content type (New page, Upgrade existing page, Refresh or Merge), Target URL, Notes.
Then list the 3 briefs I should write first.
```
