# Topic Clusters: AI prompt pack

From Brandella Journal, free to use. Full guide: https://brandella.in/resources/seo-aeo-assets/topic-clusters/

Replace the parts in [square brackets] before you paste a prompt into ChatGPT, Claude or Gemini. Always check the output against real data.

## 1. Pick pillar topics that fit the business

```
Act as an SEO strategist. My business: [what you sell] to [audience] in [country].
Suggest 8 pillar topics that are broad enough for 6 to 15 useful pages each and close to what I sell.
For each, give the pillar keyword, why it fits my business and 3 example cluster pages.
```

## 2. Map the subtopics of a pillar

```
For the pillar topic "[topic]", list every subtopic a complete, expert resource would cover for [audience].
Group them under 5 to 8 headings and mark which deserve their own page and which fit as a section of the pillar.
```

## 3. One page, one job

```
Here are my planned cluster pages with their primary keywords: [paste].
Find any two pages that would do the same job or target the same intent, and suggest how to merge or retarget them.
```

## 4. Keyword overlap and cannibalization check

```
Here are my existing URLs, titles and primary keywords: [paste].
Flag pairs of pages that compete for the same query. For each pair, recommend which URL to keep, what to merge and which redirect to add.
```

## 5. Fan out questions for a pillar

```
A person asks an AI assistant about "[pillar topic]". List 20 follow up questions it may also need to answer,
grouped by type: definition, how to, comparison, cost, problem, rules, tools, alternatives. Keep each question short and natural.
```

## 6. Match questions to my pages

```
Here are my pages with their headings: [paste URL and H2s]. Here are the questions for this pillar: [paste].
For each question, give the URL that answers it best, and say whether the answer is a full section, a short mention or missing.
```

## 7. Pillar page outline

```
Write an outline for a pillar page on "[pillar topic]" for [audience]. Include an answer first opening, H2 sections that each
introduce one cluster page (with where the link goes), a FAQ and a short next steps section. Cluster pages: [paste titles and URLs].
```

## 8. Cluster page brief

```
Write a brief for a cluster page "[title]" targeting "[primary keyword]" in the "[pillar]" cluster.
Include intent, H2 outline, questions to answer, the sentence where it links up to the pillar, 2 sibling pages to link to,
and what would make it more useful than the current top results.
```

## 9. Descriptive anchor text ideas

```
For each link below, suggest 3 natural, descriptive anchor texts of 2 to 6 words, and a sentence that places the link in context.
Avoid generic phrases like click here or read more. Links: [paste from URL, to URL and the target page topic].
```

## 10. Find orphan and weak pages

```
Here is a list of my pages with how many internal links point to each: [paste].
Which pages are orphans or close to it? For each, suggest 2 existing pages that should link to it and why.
```

## 11. Supporting page or section?

```
For each of these small questions in my "[pillar]" cluster, decide whether it deserves its own supporting page or a section
on an existing page. Explain in one line, considering search demand and how much there is to say: [paste questions].
```

## 12. Cluster gap check against competitors

```
Here are the headings of the top 3 ranking pages for "[pillar keyword]": [paste]. Here are my cluster pages: [paste].
List subtopics they cover that my cluster misses, and subtopics where I can offer first hand experience they do not.
```

## 13. Entity coverage for a cluster

```
For the topic "[pillar topic]", list the entities an expert would mention: concepts, standards, laws, tools, organizations and roles.
Mark which page in my cluster should cover each one: [paste cluster pages].
```

## 14. Breadcrumb and URL structure

```
Suggest a clean URL and breadcrumb structure for this cluster so readers can tell where each page sits: [paste pages].
Keep URLs short and readable. Note any page that should move and the redirect it needs.
```

## 15. Low CTR rewrite for a cluster page

```
My page "[title]" has [impressions] impressions and [clicks] clicks in 28 days for queries like [paste top queries].
Suggest 3 better titles and an opening paragraph that match the intent and the angle of the current top results.
```

## 16. Cluster refresh plan

```
Here is my cluster with each page's last update date and recent clicks: [paste]. Which 5 pages should I refresh first and why?
For each, list what to check: facts, examples, screenshots, links and new questions.
```

## 17. Quality check before publishing

```
Review this draft cluster page as a demanding editor: [paste draft]. Does it add original value, first hand detail and clear answers,
or does it repeat what every other page says? List the 5 changes that would most improve it for a real reader.
```

## 18. Workflow 1 of 5: brief the assistant

```
You are my content strategist. My business: [what you sell]. Audience: [who]. Country: [country].
Pillar topic: [topic]. Goal: [leads, sales or sign ups]. Site stage: [new, growing or established]. Confirm, then wait.
```

## 19. Workflow 2 of 5: map subtopics

```
List every subtopic a complete resource on the pillar topic must cover for my audience. Group them under clear headings,
and note the search intent of each one.
```

## 20. Workflow 3 of 5: group into pages

```
Group the subtopics into pages. Give each page one job, one primary keyword, a role (Pillar, Cluster or Supporting),
a title and a short readable URL. Merge anything that would compete for the same keyword.
```

## 21. Workflow 4 of 5: fan out questions

```
For this cluster, list 15 follow up questions a reader or an AI answer would need, each with its question type
and the URL from the page list above that should answer it. Mark questions no page answers yet.
```

## 22. Workflow 5 of 5: tables for Excel

```
Turn everything into three tables with tabs between columns, ready to paste into my workbook.
Table 1 (Cluster Map): Pillar, Page role, Page title, URL, Primary keyword, Subtopic, Search intent, Status (Planned).
Table 2 (Fan Out Questions): Pillar, Question, Question type, Answered by URL.
Table 3 (Link Plan): From URL, To URL, Anchor text, Link type. Include links up, down and between siblings.
```
