# Keyword Research: AI prompt pack

From Brandella Journal, free to use. Full guide: https://brandella.in/resources/seo-aeo-assets/keyword-research/

Replace the parts in [square brackets] before you paste a prompt into ChatGPT, Claude or Gemini. Always check the output against real data.

## 1. Seed keyword expansion

```
Act as an SEO strategist. My website is about [niche] for [audience] in [country].
List 40 keyword ideas grouped into: informational, commercial, transactional and question keywords.
Prefer long tail phrases real people type. Return a table with keyword, intent and why it fits my audience.
```

## 2. Customer language mining

```
Here are real messages, reviews or support tickets from my customers: [paste text]
Extract the exact phrases they use to describe their problems and goals.
Turn them into 25 search queries a real person would type or ask an AI assistant.
```

## 3. Find quick win keywords

```
Here is my keyword list with monthly volume and keyword difficulty: [paste list]
My site is a [new, growing or established] site with about [number] pages. Pick the 10 best quick wins.
Explain each choice in one line and suggest the content type most likely to rank.
```

## 4. Question mining for AI answers

```
List 25 questions people ask AI assistants and Google about [topic].
Group them by buyer stage (learn, compare, buy) and mark which ones deserve their own page versus a FAQ answer.
```

## 5. Long conversational queries

```
People now ask long, conversational questions in AI search. For the topic [topic] and audience [audience],
write 20 realistic long queries (12 to 30 words) that include context, constraints or comparisons.
Then list the short keyword each one maps to.
```

## 6. Classify intent and funnel stage

```
Classify each keyword by search intent (informational, commercial, transactional, navigational)
and funnel stage (awareness, consider, decision, retention). Keywords: [paste list]
Return a table I can paste into Excel, with one keyword per row.
```

## 7. Business value scoring

```
I sell [product or service] to [audience]. Score each keyword from 1 to 3 for business value:
3 = close to a purchase or lead, 2 = builds trust with buyers, 1 = loosely related.
Keywords: [paste list]. Return keyword, score and a one line reason.
```

## 8. Group keywords into pages

```
Group these keywords so that each group can be targeted by ONE page: [paste keywords]
Keywords with the same meaning and intent go together. Give each group a suggested page title, URL slug and primary keyword.
```

## 9. Keyword cannibalization check

```
Here are my existing page titles and URLs: [paste list]
And here are my new target keywords: [paste list]
Flag any keyword that an existing page already targets, so I update that page instead of writing a new one.
```

## 10. Spot keywords not worth targeting

```
My business sells [offer] to [audience]. From this list, remove keywords that would bring visitors who could never
become customers or loyal readers, and explain each removal in a few words: [paste list]
```

## 11. SERP and AI Overview check plan

```
For these keywords: [paste list], tell me what I should look for when I search each one manually:
AI Overview, featured snippet, People Also Ask, videos, local pack, shopping results.
Give me a short checklist and what each feature means for my content plan.
```

## 12. Answer first block for an AI Overview keyword

```
The keyword "[keyword]" shows an AI Overview. Write a 40 to 60 word answer that fully answers the query on its own,
in plain language, accurate, with no fluff. Then suggest 4 FAQ questions that should follow it on the page.
```

## 13. Entity coverage for a keyword

```
For a page targeting "[keyword]", list the entities (products, standards, organizations, concepts, places)
an expert page would mention. Mark which ones are essential and which are optional.
```

## 14. Seasonal and trend check

```
Which of these keywords are likely seasonal or trending up or down, and why? [paste list]
Suggest the best month to publish or refresh each one. I will confirm with Google Trends.
```

## 15. Local and regional variants

```
My business serves [cities or regions]. Turn these keywords into local variants people actually use: [paste list]
Include "near me" style queries only where they make sense.
```

## 16. Content type recommendation

```
For each keyword, recommend the best content type (guide, template, tool, comparison, landing page, product page)
based on intent and what usually ranks: [paste list]. One line reason each.
```

## 17. Write a content brief from a keyword group

```
Write a content brief for a page targeting "[primary keyword]" with these secondary keywords: [paste].
Include: search intent, H2 outline, questions to answer, answer first block, entities to cover, internal links to [pages],
and what would make this page more useful than the current top results.
```

## 18. Workflow 1 of 5: brief the assistant

```
You are my keyword research assistant. My business: [what you sell]. Audience: [who]. Country: [country].
Site stage: [new, growing or established]. Goal: [leads, sales or readers]. Confirm you understand, then wait for the next step.
```

## 19. Workflow 2 of 5: expand

```
Here are my seed topics: [paste seeds]. For each seed, give 15 keyword and question ideas a real person would search
or ask an AI assistant. Mix short keywords with long conversational questions.
```

## 20. Workflow 3 of 5: clean and classify

```
From all ideas above, remove duplicates and near duplicates. Classify each remaining one by intent and funnel stage,
and give a business value from 1 to 3 using my goal. Show a table.
```

## 21. Workflow 4 of 5: cluster into pages

```
Group the table above into pages. One page per group of keywords with the same intent and meaning.
Give each page a title, URL slug, content type, primary keyword and secondary keywords.
```

## 22. Workflow 5 of 5: page map for Excel

```
Turn the page groups into two tables I can paste into my workbook.
Table 1 columns: Keyword, Cluster or Topic, Search Intent, Funnel Stage, Business Value, Target URL.
Table 2 columns: Target URL, Page Title, Primary Keyword, Content Type. Use tabs between columns.
```
