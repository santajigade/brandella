# On-Page SEO: AI prompt pack

From Brandella Journal, free to use. Full guide: https://brandella.in/resources/seo-aeo-assets/on-page-seo/

Replace the parts in [square brackets] before you paste a prompt into ChatGPT, Claude or Gemini. Always check the output against real data.

## 1. Title tag options

```
Write 5 title tags for a [page type] about "[focus keyword]" for [audience]. Put the topic near the start, say what makes the page useful
([what is special]), keep each under 60 characters and promise only what the page delivers.
```

## 2. Meta description options

```
Write 3 meta descriptions for this page: [paste summary]. Each 1 or 2 sentences, specific, unique to this page, 120 to 155 characters,
with the focus keyword "[keyword]" used naturally. No keyword lists.
```

## 3. Direct answer opening

```
Here is the first paragraph of my page about "[keyword]": [paste]. Rewrite it as a direct answer in 2 or 3 sentences that answers
the main question first, uses the keyword naturally and leads into the detail. Keep my facts; do not add new ones.
```

## 4. H1 options

```
Suggest 5 H1 headings for a page whose title is "[title]" and focus keyword is "[keyword]". Clear, natural, not identical to the title.
```

## 5. Question headings

```
Here are the People also ask questions and customer questions for "[keyword]": [paste]. Pick the 5 that fit my page about [topic],
phrase each as an H2 or H3 and write a 2 sentence direct answer under each.
```

## 6. Original value ideas

```
My page about "[keyword]" is generic. My business is [what you do] and we have [data, photos, tests, customers, tools].
List 10 kinds of first hand detail I could add that no competitor page has, and where on the page each would go.
```

## 7. Alt text for images

```
Write short, specific alt text (under 125 characters) for these images on a page about [topic]: [describe each image].
Describe what is in the image. Do not stuff keywords. Say if an image is decorative and needs empty alt text.
```

## 8. Internal link finder

```
Here is a list of my site's pages with titles: [paste]. My target page is "[title]" at [URL]. Suggest 5 pages that should link to it,
the sentence where the link fits and descriptive anchor text for each.
```

## 9. Replace generic anchors

```
Here are paragraphs from my page with generic links such as "click here" or "read more": [paste with the linked URL].
Rewrite each link so the anchor text says what the linked page is about. Keep the sentence natural.
```

## 10. Structured data choice

```
My page is a [page type] about [topic] with these elements: [author, date, steps, FAQ, product, price, reviews, address].
Which schema.org types fit, which properties should I fill from what is really on the page, and what must I not mark up?
```

## 11. Byline and author box

```
Write a short author box for [name], who wrote this page about [topic]. Use only these facts: [credentials, experience, role].
Then suggest what the linked author page should include.
```

## 12. Update note

```
I updated my page about "[keyword]" with these changes: [list]. Write a one line "Last updated" note for the top of the page
and a 2 sentence summary of what changed for returning readers.
```

## 13. Core Web Vitals brief for a developer

```
My page [URL] has LCP [x] s, INP [x] ms and CLS [x] from field data. It uses [theme, plugins, hero image, embeds].
Write a short, prioritised brief for my developer with the likely causes and the first 3 things to test for each poor metric.
```

## 14. Duplicate titles and descriptions

```
These pages share the same title or description: [paste URLs with titles and descriptions]. Write a unique title and description
for each that reflects what that page alone offers.
```

## 15. Page type check

```
Here is the top of my page and its focus keyword "[keyword]": [paste]. Does the page type (guide, product, category, tool, local page)
match what someone searching this keyword wants? If not, what should change?
```

## 16. Pre publish review

```
Review this draft against an on page SEO checklist: title, description, H1, first paragraph, question headings, original value,
internal links, image alt text, byline and date. Draft: [paste]. List what passes and what to fix, most important first.
```

## 17. Quarterly re audit summary

```
Here are my page audit rows from [old date]: [paste] and today: [paste]. Summarise what improved, what slipped
and which 5 pages I should fix next, with the reason for each.
```

## 18. Workflow 1 of 5: brief the assistant

```
You are my on page SEO editor. My business: [what you sell]. Audience: [who]. The page: [URL], a [page type] about "[focus keyword]",
average position [x]. Confirm, then wait for my audit data.
```

## 19. Workflow 2 of 5: the audit row

```
Here is the Page Audit row and the fixes in priority order for the page: [paste]. Explain in plain words what each fix means
for this page and which 3 will make the biggest difference.
```

## 20. Workflow 3 of 5: rewrite the top

```
Here are the current title, meta description, H1 and first paragraph: [paste]. Rewrite all four so they name the topic clearly,
answer the main question first and stay honest. Keep my facts; mark anything you would need me to confirm.
```

## 21. Workflow 4 of 5: body fixes

```
Here are the page's current H2 headings: [paste] and the questions readers ask: [paste]. Suggest question headings to add, where my
first hand detail should go ([what we have]) and 3 related pages on my site that should link here: [paste list of pages].
```

## 22. Workflow 5 of 5: fix list for Excel

```
Turn everything above into rows with tabs between columns, ready to paste into my Fix Plan:
URL, Fix (use the check names from my audit), Owner, Due date, Status (To do), Notes. One fix per row, most important first.
```
