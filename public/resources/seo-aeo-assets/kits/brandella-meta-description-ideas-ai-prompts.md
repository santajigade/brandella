# Meta Description Ideas: AI prompt pack

From Brandella Journal, free to use. Full guide: https://brandella.in/resources/seo-aeo-assets/meta-description-ideas/

Replace the parts in [square brackets] before you paste a prompt into ChatGPT, Claude or Gemini. Always check the output against real data.

## 1. Meta description options

```
Write 5 meta descriptions for a [page type] about "[focus keyword]" for [audience]. Each 120 to 155 characters, specific to this page,
with the topic named naturally once, at least one real fact from this list: [facts], and a reason to click. No keyword lists.
```

## 2. Fix a keyword list

```
This meta description is a list of keywords: "[description]". The page covers: [summary]. Rewrite it as 2 natural sentences,
120 to 155 characters, with one real fact and the keyword "[keyword]" once.
```

## 3. Remove boilerplate openings

```
These descriptions all start with the same sentence: [paste URLs and descriptions]. Rewrite each so it starts with what is special
about that page. Keep each under 155 characters and keep the facts.
```

## 4. Unique descriptions for similar pages

```
These pages share one meta description: [paste URLs with a one line summary each]. Write a unique description for each that
says what that page alone offers.
```

## 5. Answer first opening paragraph

```
Here is the first paragraph of my page about "[keyword]": [paste]. Rewrite it as a direct answer in 2 or 3 sentences that answers
the search first, so it would make a good snippet. Keep my facts; do not add new ones.
```

## 6. Description from the page content

```
Here is my page: [paste the main text]. Write a meta description of 120 to 155 characters that summarises the whole page, names
the main topic and includes the most useful fact. Then list which sentence on the page Google could use as a snippet instead.
```

## 7. Why does Google ignore my description

```
My meta description is "[description]". For the search "[query]" Google shows "[shown snippet]". Explain the likely reasons, based
on Google's snippet guidance, and suggest a description and an opening sentence that would fit that search better.
```

## 8. Product description template

```
Here are 5 rows of my product data with these columns: [paste]. Write a meta description template with placeholders like {name},
{fact1}, {fact2}, {number} and {offer} that reads naturally for every row, then show the 5 results with their lengths.
```

## 9. Check my bulk descriptions

```
Here are 30 descriptions built from a template: [paste]. Find ones that read badly, repeat the same opening, are near duplicates
or are longer than 160 characters, and suggest a fix for each.
```

## 10. Article byline description

```
Write a meta description for my article "[title]" by [author], updated [date]. Google suggests descriptions can carry facts like
author and date. Include both, plus what the reader learns, in under 155 characters.
```

## 11. Local page description

```
Write 3 meta descriptions for my [business type] in [area]. Include the address area, opening hours ([hours]), one proof point
([proof]) and what people can do there. Under 155 characters each.
```

## 12. Category page description

```
Write a meta description for my category page "[category]" with [number] items. Say how many, how to choose between them
([main filters]) and the price range ([range]). Under 155 characters.
```

## 13. Description beyond the AI answer

```
For "[query]", an AI Overview already answers the basics. My page offers [data, tool, photos, tests, local detail].
Write 5 descriptions that promise what the summary cannot give, 120 to 155 characters, no clickbait.
```

## 14. Snippet control audit

```
Here are the robots meta tags and data-nosnippet uses on my key pages: [paste URL and tag for each]. Which ones stop Google showing
a snippet or limit it too much, what does each do, and which should I remove? Remember a page must be eligible for a snippet to be
a supporting link in AI Overviews and AI Mode.
```

## 15. Update old years

```
These descriptions mention old years: [paste]. For each, tell me if the year is needed. If the content was updated (my notes: [notes]),
write the new description; if not, write a timeless one.
```

## 16. Translate a description for another market

```
Translate this meta description for [language and country]: "[description]". Use the words people there search for "[keyword]",
keep the facts and keep it under 155 characters.
```

## 17. Read my test results

```
Here are my Test Log rows (old description, new description, CTR before and after, position before and after, days live): [paste].
Which changes look like real wins, which are unfair tests, and what should I test next?
```

## 18. Workflow 1 of 5: brief the assistant

```
You are my meta description editor. My site: [site], about [topic], for [audience]. Rules: 120 to 155 characters, the topic named
once, at least one real fact, no keyword lists, no company boilerplate at the start, nothing the page does not deliver.
Confirm, then wait for my data.
```

## 19. Workflow 2 of 5: the Description Lab row

```
Here is the Description Lab row for one page: URL, focus keyword, title, description, opening paragraph, snippet Google shows,
CTR, band average CTR, position and the fixes in priority order: [paste]. Explain in plain words what is wrong and what to fix first.
```

## 20. Workflow 3 of 5: new description and opening

```
Here are the facts from the page: [paste facts, numbers, prices, dates]. Write 6 new meta descriptions in different styles
(answer first, facts first, question, proof, offer, comparison) and one new opening paragraph that answers the search.
Show the character count of each description.
```

## 21. Workflow 4 of 5: pressure test

```
Here are the top 5 results and their snippets for "[query]": [paste]. Score each of your 6 descriptions from 1 to 5 for clarity,
facts, honesty and difference from the results above. Keep the best 2 and explain why.
```

## 22. Workflow 5 of 5: rows for Excel

```
Turn the best description into a row with tabs between columns for my Test Log: URL, Old description, New description,
Date changed ([date]), Status (Planned), Impressions before, Clicks before, Position before (use my numbers: [paste]),
Notes (the reason for the change).
```
