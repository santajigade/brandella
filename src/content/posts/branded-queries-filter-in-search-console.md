<h2 id="branded-queries-filter-in-search-console-introduction">Branded Queries Filter in Search Console: Introduction</h2>
<p>The <strong>Branded Queries Filter</strong> is Google’s latest enhancement inside Search Console, designed to help website owners better understand where their traffic is coming from.</p>
<p>With this update, you can now separate branded and non-branded search queries directly inside the Performance report.</p>
<p>This is a major improvement for <a href="/category/seo/">SEO</a> analysis in 2026.</p>
<p>Let’s break down what the Branded Queries Filter does, how it works, and why it matters.</p>
<h2 id="what-is-the-branded-queries-filter">What Is the Branded Queries Filter?</h2>
<p>The Branded Queries Filter is a new feature inside the <strong>Search Results Performance Report</strong> in <strong><a href="https://search.google.com/search-console/about" target="_new" rel="noopener">Google Search Console</a></strong>.</p>
<p>It allows you to segment your query data into two categories:</p>
<ol>
 	<li>
<p>Branded queries</p>
</li>
 	<li>
<p>Non-branded queries</p>
</li>
</ol>
<p>This helps marketers analyze whether traffic is coming from users already familiar with the brand or from new users discovering it organically.</p>
<p>The Branded Queries Filter simplifies what previously required complex manual filtering.</p>
<h2 id="what-is-a-branded-query">What Is a Branded Query?</h2>
<p>A branded query includes:</p>
<ol>
 	<li>
<p>Your company’s brand name</p>
</li>
 	<li>
<p>Variations or misspellings of your brand name</p>
</li>
 	<li>
<p>Unique products or services associated with your brand</p>
</li>
</ol>
<p>For example, queries like:</p>
<ol>
 	<li>
<p>Google</p>
</li>
 	<li>
<p>Gogle</p>
</li>
 	<li>
<p>Gmail</p>
</li>
</ol>
<p>Would be considered branded queries for google.com.</p>
<p>The Branded Queries Filter automatically identifies these using an internal AI-assisted system.</p>
<p>This means you no longer need to manually build regular expressions to isolate brand terms.</p>

<h2 id="why-differentiating-branded-and-non-branded-traffic-matters">Why Differentiating Branded and Non-Branded Traffic Matters</h2>
<p>The Branded-Queries Filter helps answer important SEO questions.</p>
<ol>
 	<li>
<p>How much traffic comes from brand recognition?</p>
</li>
 	<li>
<p>How much traffic comes from organic discovery?</p>
</li>
 	<li>
<p>Are marketing efforts increasing brand awareness?</p>
</li>
 	<li>
<p>Are non-branded keywords driving new audience growth?</p>
</li>
</ol>
<p>Branded traffic usually shows:</p>
<ol>
 	<li>
<p>Higher rankings</p>
</li>
 	<li>
<p>Higher click-through rates</p>
</li>
 	<li>
<p>Stronger conversion intent</p>
</li>
</ol>
<p>Non-branded traffic shows:</p>
<ol>
 	<li>
<p>Growth opportunities</p>
</li>
 	<li>
<p>SEO expansion</p>
</li>
 	<li>
<p>Visibility beyond your existing audience</p>
</li>
</ol>
<p>The Branded Queries Filter makes these patterns easier to analyze.</p>

<h2 id="how-the-branded-queries-filter-works">How the Branded Queries Filter Works</h2>
<p>The Branded-Queries Filter appears inside the Search Results Performance report.</p>
<p>When applied, it creates two segmented views:</p>
<ol>
 	<li>
<p>Branded</p>
</li>
 	<li>
<p>Non-branded</p>
</li>
</ol>
<p>You can use this filter across:</p>
<ol>
 	<li>
<p>Web search</p>
</li>
 	<li>
<p>Image search</p>
</li>
 	<li>
<p>Video search</p>
</li>
 	<li>
<p>News search</p>
</li>
</ol>
<p>Once applied, you can view metrics such as:</p>
<ol>
 	<li>
<p>Impressions</p>
</li>
 	<li>
<p>Clicks</p>
</li>
 	<li>
<p>Average position</p>
</li>
 	<li>
<p>Click-through rate</p>
</li>
</ol>
<p>The Branded Queries Filter ensures that these metrics reflect only the selected query type.</p>
<h2 id="new-insights-report-card">New Insights Report Card</h2>
<p>Google has also added a new breakdown card inside the Insights report.</p>
<p>This card shows:</p>
<ol>
 	<li>
<p>Total branded clicks</p>
</li>
 	<li>
<p>Total non-branded clicks</p>
</li>
</ol>
<p>This comparison helps measure brand strength.</p>
<p>If branded clicks dominate, it may indicate strong brand recognition.</p>
<p>If non-branded clicks are increasing, it suggests expanding organic visibility.</p>
<p>The Branded Queries Filter makes brand measurement far more transparent.</p>
<h2 id="how-are-branded-queries-identified">How Are Branded Queries Identified?</h2>
<p>The Branded-Queries Filter does not rely on simple keyword matching.</p>
<p>It does not use regular expressions like the traditional “Filter by query” feature.</p>
<p>Instead, classification is handled by an internal AI-assisted system.</p>
<p>This system identifies:</p>
<ol>
 	<li>
<p>Brand names in multiple languages</p>
</li>
 	<li>
<p>Misspellings</p>
</li>
 	<li>
<p>Product names strongly associated with the brand</p>
</li>
 	<li>
<p>Queries referencing unique services</p>
</li>
</ol>
<p>Because this system is dynamic, some occasional misclassification may occur.</p>
<p>However, Google clearly states that the Branded Queries Filter does not impact rankings.</p>
<p>It is strictly an analytical segmentation tool.</p>
<h2 id="rollout-and-availability">Rollout and Availability</h2>
<p>The Branded-Queries Filter is rolling out gradually.</p>
<p>It is currently available only for:</p>
<ol>
 	<li>
<p>Top-level properties</p>
</li>
 	<li>
<p>Sites with sufficient query volume</p>
</li>
</ol>
<p>It is not available for:</p>
<ol>
 	<li>
<p>URL path properties</p>
</li>
 	<li>
<p>Subdomain properties</p>
</li>
 	<li>
<p>Low-volume websites</p>
</li>
</ol>
<p>If you do not see the Branded Queries Filter in your account yet, it may not have rolled out to your property.</p>

<p>The Branded-Queries Filter changes how SEO performance is interpreted.</p>
<p>Previously, separating branded and non-branded traffic required manual setup.</p>
<p>Now the segmentation is automated.</p>
<p>This allows marketers to:</p>
<ol>
 	<li>
<p>Measure brand growth over time</p>
</li>
 	<li>
<p>Evaluate campaign effectiveness</p>
</li>
 	<li>
<p>Track organic expansion</p>
</li>
 	<li>
<p>Adjust keyword strategies</p>
</li>
</ol>
<p>The Branded Queries Filter improves clarity in performance reporting.</p>
<p>In 2026, SEO is not just about rankings.</p>
<p>It is about understanding traffic quality.</p>

<p>The Branded-Queries Filter is a valuable addition to Google Search Console.</p>
<p>It simplifies data segmentation.</p>
<p>It provides clearer brand vs discovery insights.</p>
<p>It helps marketers make better strategic decisions.</p>
<p>Most importantly, it reinforces a growing reality in SEO:</p>
<p>Brand strength and organic discovery must be measured separately.</p>
<p>The Branded Queries Filter makes that possible.</p>
