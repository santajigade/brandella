A .seo domain extension could become available to the public, but not soon. [ICANN's application record](https://newgtldprogram-aps.icann.org/applications/XL2625T-T96368-R/summary) shows an active new gTLD application for the string "seo" from XYZ.COM LLC, the US company that runs .xyz. The record was last published on November 17, 2026, the day ICANN published its final list of applications for the 2026 round.

If you run an SEO agency, sell SEO tools or write about search, a name like yourbrand.seo may look tempting. Before you plan around it, it helps to know where the application really stands, what is confirmed and what is only an estimate.

The story was picked up on November 20 by [Search Engine Roundtable](https://www.seroundtable.com/seo-tld-42582.html), which pointed to a detailed write-up by the Austrian registrar [Domaintechnik](https://www.domaintechnik.at/en/seo-domain-extension/).

## Where the .seo domain extension application stands

ICANN's record gives the official status in a few fields.

| Field | ICANN record |
| --- | --- |
| Primary string | seo |
| Application ID | XL2625T-T96368-R |
| Applicant | XYZ.COM LLC (US) |
| Application status | Active |
| Processing stage | String Evaluation Processing |
| Comment period | 17 November 2026 to 16 March 2027 |

ICANN's [November 17 announcement](https://www.icann.org/en/announcements/details/icann-confirms-2026-round-applications-input-and-objections-period-begins-updated-17-11-2026-en) says it "marked String Confirmation Day by publishing the final list of new generic top-level domain (gTLD) applications." It adds: "There are 1,606 applications proceeding in the round." The announcement does not name .seo.

## How .seo ended up on the list

According to Domaintechnik, XYZ "originally applied for .logistics and changed its application to .seo after Reveal Day." ICANN confirms that this kind of switch happened at scale: "During the String Replacement Period, applicants chose to replace 152 applied-for strings with an alternate string." ICANN does not say which strings were replaced, so the .logistics detail comes from Domaintechnik only.

Domaintechnik also reports that no other applications for .seo were submitted, and that XYZ plans to run it as an open extension that anyone can register on a first-come, first-served basis through accredited registrars. Trademark holders would get a Sunrise period first. Prices have not been announced. ICANN's record does not confirm the eligibility rules or the lack of competing applications, so treat those as the registrar's reporting.

## When could you register a .seo domain?

Domaintechnik's estimate is "a launch possible no earlier than late 2027 and open registration realistically in 2028." That is a registrar's estimate, not an ICANN date.

ICANN itself has not scheduled the next steps. Its announcement says it will keep working on "timelines for later 2026 Round milestones, such as the Prioritization Draw, publication of String Evaluation Results," and will share them later. The comment window alone runs to March 16, 2027, and ICANN says evaluators will only consider comments submitted before that date or in other official comment windows. Domaintechnik's own timeline puts a prioritization draw in the first half of 2027, followed by about 180 days of string evaluation, but again that is its estimate.

## Will a .seo domain help rankings?

Probably not in the way some people hope. Search Engine Roundtable notes that Google has long said it treats new top-level domains like generic ones, with no special ranking benefit. Domaintechnik quotes Google's position that a keyword in the extension is "neither an advantage nor a disadvantage."

What a .seo name could offer is branding: a short, memorable address that tells people what you do. Rankings still depend on the site itself. ## What SEO businesses should do now

These steps are Brandella's recommendations.

![What to do now about the .seo domain extension: five steps](/images/infographics/ig-seo-domain-extension-icann-2.webp)

1. Don't move your main site. A new extension gives no ranking boost, and a domain migration always carries risk.
2. If you own a trademark, note the Sunrise period. Trademark holders are expected to get first access before general availability.
3. Be careful with paid pre-registration offers. ICANN has not approved the string or set any dates, and prices are unknown.
4. Watch ICANN's record for status changes, and the ICANN announcements page for the Prioritization Draw date.
5. If you have concerns or support for the application, the public comment window on ICANN's system is open until March 16, 2027.

If you do eventually buy a .seo name for a campaign or a tool, plan redirects and canonical tags the same way you would for any new domain. Our post on [how to increase domain authority naturally](/how-to-increase-domain-authority-naturally/) explains why a fresh domain starts from zero.

## FAQ about the .seo domain extension

### Who applied for the .seo domain extension?

XYZ.COM LLC, a US company that also operates the .xyz extension, according to ICANN's application record.

### Is .seo approved yet?

No. ICANN lists the application as Active and in String Evaluation Processing, with a comment period until March 16, 2027.

### When will .seo domains be available?

ICANN has not set dates. The registrar Domaintechnik estimates a launch no earlier than late 2027 and open registration realistically in 2028.

### Does a .seo domain rank better on Google?

Google has long said new domain extensions get no special ranking benefit, so a .seo address alone will not improve rankings.
