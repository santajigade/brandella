Perplexity Teammates are a new kind of AI agent built to take ownership of ongoing work instead of answering one prompt at a time. Perplexity announced them in a [blog post dated November 4, 2026](https://www.perplexity.ai/hub/blog/teammates-are-agents-for-complex-ongoing-work), describing personal agents that plan and coordinate projects, adjust when priorities change and bring finished work back for review.

Access is limited to Perplexity Max subscribers for now, on the web first, with iOS listed as coming soon. [Engadget reported](https://www.engadget.com/2308870/perplexity-teammates-ai-agents-for-ongoing-work/) that Max costs $200 a month or $2,000 a year.

For marketers, the interesting part is the first use case Perplexity lists: a marketing Teammate that manages social posts, email, ads and SEO, watches performance and competitor promotions, and drafts fixes when results slip. That is a direct pitch at the day to day work of small marketing teams.

## What Perplexity Teammates actually are

Teammates build on Perplexity Computer, which Perplexity introduced in February 2026 as a general purpose digital worker that uses the same software tools a person would. [Dataconomy](https://dataconomy.com/2026/11/06/perplexity-launches-always-on-ai-agents-for-work/) notes that Teammates can run different jobs at the same time in a shared workspace. The difference from a regular Computer session is time. A Computer session handles a task; a Teammate is meant to keep owning a stream of work across many runs.

Perplexity says a Teammate can coordinate Computer sessions and even other Teammates. In its words, "Teammates represent a new way of working with AI." If you are new to the idea, our plain English guide to [what an AI agent is](/what-is-an-ai-agent/) covers the basics.

## Key features of Perplexity Teammates

Here is what Perplexity's announcement says each Teammate gets.

| Feature | What Perplexity says it does |
|---|---|
| Separate environment | Each Teammate runs in its own environment, with browser sessions kept apart from other Teammates |
| Memory | Keeps project goals, task history and shared files across runs, and applies your feedback to later work |
| Skills and Projects | Uses your existing Computer Projects, skills and memory |
| Connectors | Plugins such as Slack, GitHub and Gmail; for GitHub you choose which repositories it can reach |
| Schedules | Acts on a schedule without a new prompt, for example a weekly pipeline review |
| Approvals | Sends progress updates and approval requests until the work is done |
| Collaboration | Can be added to Slack channels, take tasks from colleagues and hand work to other Teammates |
| Security | Inherits Computer's tool and Project permissions; saved credentials are encrypted |

You can also review completed work, take over the agent's desktop or redirect it in the middle of a task. That human handover point matters, because it is how you keep control of anything that touches customers or budgets.

## Use cases Perplexity highlights

Perplexity lists four example roles. Marketing is the first: managing social posts, email, ads and SEO, monitoring results and competitor promotions, drafting fixes and suggesting price responses.

The other three are sales (spotting opportunities in inquiries and stalled conversations, preparing outreach and following up), customer support (summarizing daily complaints and drafting replies) and operations (tracking deadlines, vendors and paperwork, and chasing missing items 72 hours before a deadline).

Setup, according to Perplexity, takes a few steps on the web: select Teammates, give it a name, connect tools, describe the work and when it should act, then assign it to a Project with a first task.

## What is still unclear

The announcement leaves some gaps. Perplexity does not state regional availability or any usage limits for Teammates, and it says access and features will expand "in the coming weeks." Treat early results as a preview of a product that is still changing.

There is also the question of accuracy. Any agent that drafts ad changes or customer replies can make mistakes, and Perplexity's design leans on approval requests for that reason. Plan for review time rather than assuming the work arrives ready to publish.

## What marketers should do now

These steps are Brandella's suggestions for testing Perplexity Teammates safely, not official Perplexity guidance.

1. **Pick one narrow, repeatable job.** Good first tests are a weekly competitor promotion summary, a daily digest of customer complaints or a weekly report on top landing pages. Avoid anything that spends money on day one.
2. **Write the brief like you would for a new hire.** State the goal, the sources it should check, the format you want and when it should act. Vague briefs produce vague work.
3. **Limit connector access.** Connect only the tools the job needs. For GitHub, choose specific repositories rather than all of them.
4. **Keep approvals on for anything public.** Social posts, emails, ad edits and price changes should all go through an approval request before they go live.
5. **Use memory deliberately.** Give feedback on the first few outputs so the Teammate learns your rules, then check that later work actually reflects that feedback.
6. **Measure time saved, not just output.** Track how long you spend reviewing and fixing its work. If review takes as long as doing the job yourself, the use case is not ready.
7. **Compare against what you already run.** If you use other automations, see our list of [AI automation workflows](/ai-automation-workflows-every-business/) and decide whether a Teammate replaces one or just adds another tool to manage.
